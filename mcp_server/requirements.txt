# MCP server runtime.
#
# stdio mode (``python -m mcp_server``) only needs ``mcp``. The HTTP /
# Streamable-HTTP mode (``python -m mcp_server.http_server``) also
# needs ``uvicorn`` to serve the ASGI app. Both are listed here so a
# single ``pip install -r mcp_server/requirements.txt`` covers the
# whole MCP surface.
#
# The container image (Dockerfile) installs both alongside the main
# web app deps so the same image can boot either the Flask service or
# the MCP HTTP service (chosen by the Render service's start command).
#
# Pin to the modern FastMCP API (>=1.2). The SDK is pure-Python and
# brings in pydantic, anyio, httpx — all already transitive deps of
# anthropic + flask, so the install footprint here is small.
mcp>=1.2.0
uvicorn>=0.30
